# Industrial Motor Control and Electrical Interlocking System

## Overview
Developed during internship training at Nian Drive Controls. This project demonstrates industrial motor control using relays, contactors, overload relays, and electrical interlocking techniques.

## Objectives
- Control motor operation safely.
- Prevent simultaneous activation of forward and reverse contactors.
- Understand relay logic and industrial control wiring.
- Gain practical experience in troubleshooting and testing.

## Components Used
- Contactors
- Overload Relays
- Push Buttons
- Control Transformer
- Limit Switches
- Control Panel Accessories

## Skills Acquired
- Control Panel Wiring
- Electrical Interlocking
- Relay Logic
- Motor Control Circuits
- Electrical Schematic Reading
- Industrial Troubleshooting
